# LU-разложение: пояснение к main.py

## Задание

Реализовать LU-разложение с выбором главного элемента. С его помощью решить СЛАУ (систему линейных алгебраических уравнений), вычислить определитель и обратную матрицу:

```text
9*x1 - 5*x2 - 6*x3 + 3*x4 = -8
  x1 - 7*x2 +   x3        = 38
3*x1 - 4*x2 + 9*x3        = 47
6*x1 -   x2 + 9*x3 + 8*x4 = -8
```

## Обозначения, которые встречаются в коде

Матрица — таблица чисел, записанная списком строк. Вектор — список чисел. `A[i][j]` — элемент строки `i`, столбца `j`. Индексы начинаются с нуля: `x[0]` — неизвестная `x1`. Главная диагональ — элементы `A[i][i]`.

| Обозначение | Смысл |
| --- | --- |
| `A`, `b`, `x` | Коэффициенты, правые части и решение. Строка `A` — одно уравнение, столбец — коэффициенты при одной неизвестной. |
| `n` | Число уравнений и неизвестных: `len(A)`. Матрица квадратная. |
| `L` | Нижняя треугольная матрица: выше диагонали нули, на ней единицы, ниже — коэффициенты исключения. |
| `U` | Верхняя треугольная матрица: ниже диагонали нули. Это преобразованная матрица `A`. |
| `P`, `permutation` | Перестановки строк. Матрицу `P` заменяет список с новым порядком исходных строк. |
| `z` | Промежуточный вектор, также названный `y` в задании. |
| `I`, `unit_vector` | Единичная матрица: на диагонали единицы, вне её нули. `unit_vector` — её столбец. |
| `inverse_matrix` | Обратная матрица: `A * inverse_matrix = I`. |

`A * x = b` — запись исходной системы: коэффициенты каждой строки умножаем на соответствующие неизвестные и складываем, получая число из `b`. Звёздочка здесь — математическое умножение; произведения матриц и векторов программа вычисляет циклами.

## С чего начинать чтение

Нижняя строка `main()` запускает решение. Определения функций выше выполняют свои вычисления только при вызове.

Читай `main()` сверху вниз, переходя в вызываемые функции: **данные → LU → вывод L и U → решение → определитель → обратная матрица → проверки**. `print_matrix()` только печатает числа.

## 1. LU-разложение — lu_decomposition(A)

Идея метода Гаусса: вычитать из нижних уравнений ведущую строку, умноженную на подходящее число, получая нули под диагональю. Эти числа сохраняем в `L`, преобразования выполняем в `U`.

Сначала копируем строки `A` в `U`, сохраняя исходные данные. В `L` ставим единицы на диагонали и нули вне её. `permutation` содержит `0, 1, ..., n-1`; `swap_count` считает обмены строк.

Далее `k` — номер ведущего столбца и ведущей строки текущего шага:

1. Находим `pivot_row`: строку с максимальным `abs(U[i][k])` среди строк от `k` до `n-1`. `abs()` — модуль числа. Выбор помогает избегать деления на слишком маленькое число.
2. Меняем нужные строки `U` и номера в `permutation`, увеличиваем `swap_count`. В `L` меняем только заполненные столбцы `j < k`: коэффициенты должны следовать за своими строками. Порядок неизвестных сохраняется.
3. Для каждой нижней строки `i` вычисляем:

   ```python
   multiplier = U[i][k] / U[k][k]
   L[i][k] = multiplier
   ```

   `multiplier` показывает, на какое число умножить ведущую строку перед вычитанием. На первом шаге для второй строки это `1 / 9`.

4. Цикл по `j` изменяет элементы справа от ведущего столбца:

   ```python
   U[i][j] = U[i][j] - multiplier * U[k][j]
   ```

   `U[i][k]` явно записываем как ноль. Повторяем для нижних строк и следующих столбцов.

Шагов `n - 1`: под последней строкой исключать нечего. Последний диагональный элемент проверяем отдельно. Если модуль ведущего элемента не больше `eps = 1e-12`, возникает `ValueError`: `main()` печатает сообщение и завершает работу.

Получаем **`P * A = L * U`**: произведение `L` и `U` восстанавливает `A` с переставленными строками. У нас `permutation = [0, 1, 3, 2]`: третья и четвёртая строки поменялись местами.

## 2. Решение системы — solve_with_lu(L, U, permutation, b)

Из `A * x = b` после перестановок получаем `L * U * x = P * b`. Обозначаем `U * x` через `z` и решаем две более простые системы.

Правые части переставляем вместе с уравнениями:

```python
permuted_b[i] = b[permutation[i]]
```

**Прямая подстановка: `L * z = P * b`.** Идём сверху вниз: в строке `i` нужны только уже найденные `z[j]` с `j < i`. Их вклад собирает `sum_of_previous_terms`:

```python
z[i] = permuted_b[i] - sum_of_previous_terms
```

Делить не нужно: на диагонали `L` единицы. В первой строке сумма пуста и равна нулю.

**Обратная подстановка: `U * x = z`.** Идём снизу вверх: в последнем уравнении осталась одна неизвестная; выше используем уже найденные `x[j]` с `j > i`. Их вклад собирает `sum_of_known_terms`:

```python
x[i] = (z[i] - sum_of_known_terms) / U[i][i]
```

Цикл `range(n - 1, -1, -1)` перебирает индексы от `n - 1` до `0`. Функция возвращает сначала `z`, затем `x`.

## 3. Определитель — вычисляется в main()

Ненулевой определитель квадратной матрицы означает, что решение единственно и обратная матрица существует.

У треугольной матрицы определитель равен произведению диагональных элементов. Вычитание кратной строки его не меняет, а каждый обмен строк меняет знак. Поэтому:

```text
det(A) = (-1)^swap_count * U[0][0] * ... * U[n-1][n-1]
```

Начинаем с `determinant = 1`, умножаем диагональ и меняем знак при `swap_count % 2 == 1` — нечётном числе обменов.

## 4. Обратная матрица — inverse_from_lu(L, U, permutation)

Нужно получить `A * inverse_matrix = I`. Для этого каждый столбец обратной матрицы находим как решение отдельной системы:

```text
A * первый столбец  = [1, 0, 0, 0]
A * второй столбец  = [0, 1, 0, 0]
... и так далее
```

Для каждого `column` создаём `unit_vector`, вызываем `solve_with_lu()` и записываем `column_solution[i]` в `inverse_matrix[i][column]`. Решение становится столбцом. Промежуточный `z` здесь больше не нужен.

**Разложение выполняется один раз:** используем те же `L`, `U`, `permutation`, повторяя только подстановки.

## 5. Проверки — последние циклы в main()

При умножении матриц элемент результата — сумма произведений элементов строки первой матрицы и столбца второй. Поэтому, например, цикл по `k` накапливает `L[i][k] * U[k][j]`. При умножении на вектор аналогично суммируются `A[i][j] * x[j]`.

| Что проверяем | Как это отражено в коде | Результат нашего варианта |
| --- | --- | --- |
| `P * A ≈ L * U` | Сравниваем `A[permutation[i]][j]` с вычисленным `lu_element`. | `max_lu_error ≈ 1.11e-16` |
| `A * x ≈ b` | Считаем `residual[i] = ax_element - b[i]`. Это невязка: насколько не выполняется уравнение. | `max_residual = 0` |
| `A * inverse_matrix ≈ I` | Сравниваем `product_element` с единицей на диагонали и нулём вне её. | `max_inverse_error ≈ 4.44e-16` |

Каждый `max_...` хранит наибольшее абсолютное отклонение; допуск — `check_tolerance = 1e-9` (0.000000001). Малые ошибки возникают из-за вычислений с дробными числами. Округляется только вывод: `.6f` — шесть знаков после точки, `.3e` — запись через степень десяти, например `1e-12 = 10⁻¹²`.

Итог: **`x ≈ [0, -5, 3, -5]`, `det(A) ≈ -4239`**. Эти ответы получены вычислениями, в алгоритм они не подставлены.

Запуск: `python main.py` из папки с программой. Размер задаётся через `n`, поэтому код работает и с другими квадратными матрицами с допустимыми ведущими элементами.
