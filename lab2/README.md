# ЛР №2. Нелинейное уравнение и система

Вариант №3. Из папки лабораторной запусти `python 2.1/main.py` или `python 2.2/main.py`. Сначала появится таблица итераций, затем откроется график.

## 2.1. Найти положительный корень

Дано уравнение $\sqrt{1-x^2}+0.1=e^x$. Функция `f()` вычитает правую часть из левой. Ищем положительное $x$, при котором эта разность равна нулю.

1. **Прочитай график.** Синяя линия показывает $\sqrt{1-x^2}+0.1$, оранжевая — $e^x$. При пересечении высоты равны, поэтому их разность $f(x)$ равна нулю. Корень — это **координата $x$ пересечения**. В `main()` проверяем, что при $0.08$ разность положительна, а при $0.10$ отрицательна. Берём $x_0=0.10$. На правом конце $f$ и $f''$ одного знака, что подходит для старта Ньютона. [График](2.1/main.py#L79) · [Выбор старта](2.1/main.py#L106)
2. **Покажи, как меняется $x$.** В `simple_iteration()` подставляем текущее $x$ в $\varphi(x)=\ln(\sqrt{1-x^2}+0.1)$ и получаем следующее $x$. Код умножает последний шаг на $q/(1-q)$ и сравнивает оценку ошибки с допуском. Здесь $q=0.10$ ограничивает скорость изменения $\varphi$ на отрезке. В `newton()` функция `df()` даёт наклон касательной. Где касательная пересекает ось $x$, там и берём новое приближение. Остановка требует малого шага и малой невязки. [Простая итерация](2.1/main.py#L12) · [Ньютон](2.1/main.py#L33)
3. **Разбери первый шаг.** Подставь $x=0.10$ в строку с `x_new`. У простой итерации выходит $\ln(\sqrt{0.99}+0.1)\approx0.090743$. У Ньютона выражение `x - f(x) / derivative` даёт $0.091554$. Каждый метод записывает своё новое число в `history` и использует его на следующем шаге. [Подстановка в $\varphi$](2.1/main.py#L18) · [Поправка Ньютона](2.1/main.py#L43)
4. **Объясни таблицу.** При допуске $10^{-6}$ простая итерация сделала 4 шага, Ньютон — 3. Корень около $0.09149015$. Ошибка в таблице показывает расстояние до контрольного корня. Невязка $|f(x)|$ показывает, насколько близка к нулю разность высот. [Вывод](2.1/main.py#L56)

## 2.2. Найти две положительные координаты

Теперь ищем пару чисел. Функция `equations()` возвращает две левые части $F_1=(x_1^2+16)x_2-64$ и $F_2=(x_1-2)^2+(x_2-2)^2-16$. У решения обе части равны нулю. [Уравнения](2.2/main.py#L4)

1. **Прочитай график.** Каждая кривая показывает пары $(x_1,x_2)$, подходящие для одного уравнения. Синяя — $x_2=64/(x_1^2+16)$, оранжевая — часть окружности. В пересечении одна пара подходит обоим уравнениям. Синяя точка $(5.9,1.25)$ показывает, откуда начинаем расчёт. [График](2.2/main.py#L101)
2. **Покажи, как меняется пара.** `phi()` берёт новый $x_1$ с правой ветви окружности, а новый $x_2$ — из формулы синей кривой. Обе координаты считаются из **старой пары**. Ньютон собирает Якобиан — таблицу производных обоих уравнений по обеим координатам. Из этой таблицы и текущих невязок находит две поправки и прибавляет их к координатам. Простая итерация останавливается по оценке ошибки, Ньютон — когда обе поправки укладываются в допуск. [Простая итерация](2.2/main.py#L10) · [Ньютон](2.2/main.py#L39)
3. **Разбери первый шаг.** В `phi()` подставь старое $x_2=1.25$ в формулу $2+\sqrt{16-(x_2-2)^2}$, а старое $x_1=5.9$ — в $64/(x_1^2+16)$. Получится новая пара $(5.929058,1.259595)$. В `newton()` из той же стартовой пары сначала получаем $F_1=-0.4875$ и $F_2=-0.2275$. Затем решаем $J\Delta=-F$ и прибавляем `delta1` и `delta2`. [Подстановка](2.2/main.py#L10) · [Расчёт поправок](2.2/main.py#L44)
4. **Объясни ответ.** Получили около $(5.929263,1.251071)$. При допуске $10^{-6}$ простая итерация сделала 8 шагов, Ньютон — 3. Ошибка в таблице — большее из двух отклонений от контрольной пары. Две невязки показывают, насколько близка к нулю левая часть каждого уравнения. [Вывод](2.2/main.py#L70)
