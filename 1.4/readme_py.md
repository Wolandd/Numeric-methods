# Часть 1.4. Метод вращений Якоби — пояснение к main.py

**Задание:** найти собственные значения и собственные векторы симметрической матрицы методом вращений Якоби с заданной точностью; проанализировать изменение показателя погрешности по итерациям.

## Что ищем и что означают обозначения

Матрица — таблица чисел, вектор — столбец чисел, хранящийся списком. Главная диагональ — элементы `A[i][i]`. Симметричность означает `A[i][j] = A[j][i]`. Индексы Python начинаются с нуля.

Ищем пары **A·v = λ·v**: ненулевой собственный вектор `v` и собственное значение `λ`. Действие матрицы на такой вектор равносильно умножению всех его компонентов на `λ`: например, `λ = 2` удваивает вектор, `λ = −1` меняет направление на противоположное.

| В коде | Смысл |
|---|---|
| `A`, `n` | Исходная матрица и её размер: `n = len(A)`. |
| `current_A`, `final_A` | Матрица в процессе вращений и результат, полученный в `main()`. |
| `i`, `j` | Индексы выбранного элемента: строка и столбец. |
| `max_element` | Наибольший модуль элемента выше диагонали. |
| `angle`, `cos_angle`, `sin_angle` | Угол вращения, его косинус и синус. |
| `rotation` (`U`), `rotation_T` | Матрица одного вращения и её транспонированная версия `U^T`. |
| `eigenvectors` (`V`) | Произведение всех вращений; его столбцы станут собственными векторами. |
| `eigenvalues` | Собственные значения в порядке соответствующих столбцов `V`. |
| `error`, `epsilon` | Текущее значение показателя `t(A)` и допустимый порог для него. |
| `errors`, `iterations` | История `t(A)` и количество выполненных вращений. |

**Идея:** вращениями координатных осей делаем матрицу почти диагональной, сохраняя собственные значения. У диагональной матрицы каждая ось масштабируется своим диагональным числом. Поэтому диагональ даст значения `λ`, а накопленные вращения — соответствующие направления `v` в исходных координатах.

## Как читать программу и объяснять решение

**1. Начинаем с `main()`, вызванной внизу файла.** Задаём матрицу, `epsilon = 0.000001`, лимит `max_iterations = 10000`. Проверяем размер, квадратность, положительную конечную точность, симметричность. `math.isclose()` допускает небольшую погрешность представления чисел.

**2. В `method_rotation()`** копируем строки `A` в `current_A`, сохраняя оригинал для проверки. Создаём `eigenvectors = I`: единицы на диагонали, остальные элементы нулевые. Умножение на единичную матрицу `I` ничего не меняет.

**3. Вычисляем начальный показатель в `calculate_error()`:**

```text
t(A) = sqrt(сумма квадратов A[i][j] при i < j)
```

В `sum_squares` складываем квадраты элементов выше диагонали, затем извлекаем корень через `math.sqrt()`. Симметричные элементы снизу повторно не учитываем. `t(A)` показывает близость к диагональному виду; точную ошибку собственных значений или векторов он не выражает.

Записываем начальное значение в `errors`, задаём `iterations = 0`. Цикл `while` работает, пока `error > epsilon` и не исчерпан лимит.

**4. Выбираем элемент для обнуления.** Циклы просматривают позиции `column > row`. `abs()` даёт модуль числа. Сохраняем максимальный модуль в `max_element`, позицию — в `i`, `j`.

**5. Вычисляем угол и строим вращение.** Используем элементы текущей матрицы:

```python
difference = current_A[i][i] - current_A[j][j]
angle = 0.5 * math.atan(2 * current_A[i][j] / difference)
```

`math.atan()` — арктангенс. Формула подбирает угол для обнуления элемента. При `difference == 0` берём `math.pi / 4` (45°), избегая деления на ноль.

Затем считаем косинус и синус, создаём единичную `rotation` и заменяем четыре элемента:

```python
rotation[i][i] = cos_angle
rotation[j][j] = cos_angle
rotation[i][j] = -sin_angle
rotation[j][i] = sin_angle
```

Это поворот в плоскости выбранных координат. Знаки синуса важны для следующей формулы.

**6. Преобразуем матрицу: `A_new = U^T · A_current · U`.** В коде это четыре последовательные строки:

```python
rotation_T = transpose_matrix(rotation)
temp = multiply_matrices(rotation_T, current_A)
new_A = multiply_matrices(temp, rotation)
current_A = new_A
```

`transpose_matrix()` меняет строки и столбцы местами. Для вращения `U^T` соответствует обратному повороту. В `multiply_matrices()` циклы `i`, `j` выбирают элемент результата; цикл `k` складывает произведения элементов строки левой матрицы и столбца правой.

Выбранный элемент становится близок к нулю благодаря преобразованию. Остальные элементы вне диагонали ещё могут требовать вращений.

**7. Накапливаем векторы и повторяем:**

```python
eigenvectors = multiply_matrices(eigenvectors, rotation)
```

Получаем `V = I·U1`, затем `V = U1·U2` и далее: сохраняем направления новых осей в исходных координатах. Увеличиваем `iterations`, пересчитываем `error`, добавляем в `errors`. Одно вращение — одна итерация; `errors[0]` — состояние до вращений.

**8. Забираем результат.** Диагональные элементы `current_A[i][i]` записываем в `eigenvalues`. Вектор для `eigenvalues[j]` — именно **столбец** `eigenvectors[i][j]` при переборе всех `i`.

Возвращаем `eigenvalues, eigenvectors, current_A, iterations, errors`. В `main()` третий результат называется `final_A`. Если последнее значение `errors[-1] > epsilon`, сообщаем об исчерпании лимита. Иначе печатаем решение и историю. При подходящем начальном `t(A)` вращений будет ноль.

## Как проверяем и анализируем результат

В оставшейся части `main()` выполняем две проверки:

- **`A·v ≈ λ·v`.** Извлекаем столбец в `vector`. Для каждой строки исходной `A` сумма `A[i][k] * vector[k]` даёт `left_part`, а `eigenvalues[j] * vector[i]` — `right_part`. Максимальная абсолютная разность `max_difference` должна быть близка к нулю.
- **`V^T·V ≈ I`.** Диагональные единицы означают единичную длину векторов, нули вне диагонали — взаимную перпендикулярность. Максимальное отклонение `max_orthogonal_error` также должно быть близко к нулю.

По `errors` проверяем убывание и считаем уменьшение `errors[0] / errors[-1]`, отдельно обрабатывая ноль. Затем повторяем тот же метод для трёх точностей. Меньшая `epsilon` может потребовать больше вращений; иногда их число совпадает.

Для данного варианта получено:

| `epsilon` | Вращения | Итоговый `t(A)` |
|---|---:|---:|
| `0.01` | 4 | `5.3586e-3` |
| `0.0001` | 5 | `4.6743e-5` |
| `0.000001` | 6 | `3.0651e-8` |

Собственные значения: **8.7054673777, −6.2393735233, 0.5339061455**. Начальное `t(A) = sqrt(35) ≈ 5.91608` уменьшилось в `1.93e8` раз. Максимальная невязка `A·v − λ·v` — `2.79e-8`, отклонение `V^T·V` от `I` — `2.22e-16`. Запись `e-8` означает умножение на `10⁻⁸`.

`v` и `−v` соответствуют одному собственному значению. Округляем только при печати. Для другого варианта меняем `A` и `epsilon` в `main()`.
