# Часть 1.3. Методы Якоби и Зейделя — пояснение к main.py

**Задание:** решить систему линейных алгебраических уравнений (СЛАУ) методами Якоби и Зейделя, сравнить число итераций и проверить решения подстановкой. Оба метода последовательно уточняют приблизительные значения неизвестных.

## Обозначения

| В коде | Смысл |
|---|---|
| `A` | Таблица коэффициентов: строка — уравнение, столбец — неизвестная. |
| `b` | Список чисел справа от знаков равенства. |
| `x` | Список искомых значений неизвестных. |
| `n` | Число уравнений и неизвестных: `n = len(A)`. |
| `i`, `j` | Номер строки и столбца; отсчёт с нуля: `x[0]` — это x₁. |
| `epsilon` | Допустимая абсолютная ошибка каждого найденного неизвестного. |

Вектор — обычный список чисел, матрица — таблица чисел. Модуль `abs()` даёт величину числа без знака.

**A·x = b** означает: в каждой строке сумма произведений коэффициентов на неизвестные равна правой части. Главная диагональ — элементы `A[i][i]`, у которых совпадают номера строки и столбца.

## Ход решения и его отражение в коде

**1. Начинаем с `main()`: она вызывается внизу файла.** Здесь заданы `A`, `b`, `epsilon`, размер `n` и предел `max_iterations = 10000`. Далее проверяются размеры, положительная точность, ненулевая диагональ и допустимость чисел.

**2. Выражаем каждую неизвестную через остальные.** Получаем систему **x = beta + alpha·x** по формулам (1.18) пособия:

```python
beta[i] = b[i] / A[i][i]
alpha[i][j] = -A[i][j] / A[i][i]  # Если i != j.
alpha[i][i] = 0
```

`beta` — свободные числа после деления, `alpha` — коэффициенты при остальных неизвестных. Минус появляется при переносе слагаемых вправо. Например, первое уравнение превращается в:

```text
x1 = 26/23 - 7/23*x2 + 5/23*x3 + 2/23*x4
```

**3. Проверяем сходимость:** приближают ли повторные пересчёты значения к решению. Норма выражает величину матрицы одним числом:

- `q = ||alpha||`: складываем модули элементов каждой строки (`row_sum`), выбираем максимальную сумму.
- `norm_C = ||C||`: аналогично, но только выше диагонали, где `j > i` (`row_sum_C`). Диагональ нулевая; отдельная матрица `C` не создаётся.

`q < 1` достаточно для сходимости обоих методов и применения оценок погрешности ниже. Здесь `q = 20/21 ≈ 0.952381`, `norm_C = 13/21 ≈ 0.619048`.

**4. Выполняем `metod_yakobi()`.** `x_old = beta.copy()` задаёт начальное приближение отдельной копией `beta`. Один полный пересчёт всех неизвестных — **итерация**. Её считает `iterations`; начальное приближение не учитывается. `x_new` — список для новых результатов, его нули служат местами для записи.

Начинаем с `new_value = beta[i]`, циклом добавляем `alpha[i][j] * x_old[j]`, записываем результат в `x_new[i]`. **Все новые компоненты зависят только от старого вектора** — формула (1.19).

**5. Выполняем `metod_zeidelya()`.** Начало — такая же копия `beta`. Отличие в двух циклах:

- `range(i)`, то есть `j < i`: используем уже обновлённые `x_new[j]`.
- `range(i + 1, n)`, то есть `j > i`: используем ещё старые `x_old[j]`.

При `j == i` слагаемое нулевое. **Зейдель сразу использует новые значения внутри текущей итерации.**

**6. После каждого пересчёта проверяем точность.** `diff = abs(x_new[i] - x_old[i])`, а `max_diff` — максимальная разность. Она показывает изменение приближений, но ещё не ошибку относительно точного решения.

При `q < 1` по пособию вычисляем верхнюю оценку ошибки:

```python
error = q / (1 - q) * max_diff       # Метод Якоби, формула (1.20).
error = norm_C / (1 - q) * max_diff  # Метод Зейделя.
```

При `error <= epsilon` точность всех компонентов достигнута. Иначе `x_old = x_new.copy()` и итерация повторяется. Меньшая `epsilon` обычно требует больше итераций.

При `q >= 1` сходимость возможна, но эти оценки неприменимы. Используется `error = max_diff` с предупреждением: такой практический критерий не гарантирует точность решения.

**7. Возвращаем результат в `main()`:** приближение `x`, счётчик `iterations`, величину `error`, признак `success`. `True` означает выполнение выбранного критерия. При исчерпании лимита возвращается последнее приближение с `False`.

`isfinite()` проверяет конечность числа: при бесконечности или `NaN` («не число») вычисления прекращаются с `None` вместо решения и `False`. Начальное `error = float("inf")` — служебное значение до первой оценки.

**8. Выводим и проверяем.** `print_result()` печатает результаты и статус. Если оба метода выполнили критерий, `main()` сравнивает решения и число итераций.

В `max_nevyazka()` сумма произведений `A[i][j] * x[j]` образует `left_part`. Невязка `residual = left_part - b[i]` показывает несовпадение левой и правой частей уравнения. Функция возвращает максимальный модуль невязки. Малое значение подтверждает хорошее выполнение уравнений; невязка и ошибка неизвестных — разные величины.

## Результаты проверки

Оба метода получают **x ≈ [1, 2, 3, −2]** без использования контрольного решения.

| `epsilon` | Итерации Якоби | Итерации Зейделя |
|---|---:|---:|
| `0.000001` | 15 | 10 |
| `0.01` | 8 | 5 |

При `epsilon = 0.000001` оценки погрешности: `4.89·10⁻⁷` и `3.54·10⁻⁷`; невязки: `1.42·10⁻⁷` и `2.77·10⁻⁸` соответственно. Зейдель здесь требует на 5 итераций меньше; для других систем это не гарантируется.

Для другой системы меняют только `A`, `b`, `epsilon` в `main()`. Округление применяется только при печати.
