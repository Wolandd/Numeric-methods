# ЛР №3. Интерполяция, МНК, производные и интеграл

Вариант №3. Из папки лабораторной запусти `python 3.1/main.py`, подставив номер нужной части. Для защиты удобно открыть `main()`, показать входные данные, затем перейти к функции, которая считает ответ.

## 3.1. Лагранж и Ньютон

- **Что ищем.** Для каждого из двух наборов по четыре узла строим многочлен степени не выше трёх. Он проходит через все четыре точки. Для каждого узла программа вычисляет $y_i=\tan x_i$, затем оценивает $\tan x$ между узлами в точке $X^*=3\pi/16$.
- **Что делает код.** `lagrange_value()` складывает вклады узлов. Вес каждого узла равен 1 в своём узле и 0 в остальных. `divided_differences()` строит коэффициенты Ньютона по столбцам. Сначала делит разности соседних $y$ на расстояния между узлами, затем так же обрабатывает полученные разности. `newton_value()` подставляет эти коэффициенты в многочлен.
- **Один шаг.** Первые узлы в обоих наборах — $0$ и $\pi/8$. Первая разделённая разность равна $(\tan(\pi/8)-0)/(\pi/8-0)\approx1.05479$. Это `coefficients[1]` в форме Ньютона, коэффициент перед $(x-x_0)$. [Расчёт разности](3.1/main.py#L20)
- **Что показать.** На одном наборе обе формулы дают один многочлен. В $X^*$ сравниваем его значение с $\tan X^*$. Ошибки для наборов **а** и **б** примерно $0.02357$ и $0.08293$. [Код 3.1](3.1/main.py)

## 3.2. Кубический сплайн

- **Что ищем.** Между каждой парой узлов строим свой кубик. На стыках должны совпасть высоты, наклоны и вторые производные. На концах вторые производные равны нулю.
- **Что делает код.** `build_spline()` вычисляет ширины интервалов и наклоны. Из условий стыковки собирает систему для $c_i=S''(x_i)/2$. В каждом уравнении участвуют только соседние узлы, поэтому подходит прогонка. В `progonka()` идём слева направо, выражая неизвестную через следующую, затем находим значения справа налево.
- **Один шаг.** На первом интервале ширина $h=0.9-0=0.9$, а наклон между табличными точками равен $(0.36892-0)/0.9\approx0.40991$. Ширины идут в `widths`, наклоны — в `slopes`. После прогонки код использует найденные $c_i$, чтобы собрать коэффициенты каждого кубика $(a,b,c,d)$. [Ширины и наклоны](3.2/main.py#L31) · [Коэффициенты](3.2/main.py#L59)
- **Что показать.** Точка $1.5$ лежит между $0.9$ и $1.8$. В кубик этого участка подставляем расстояние $1.5-0.9$ от его начала. Получаем $S(1.5)\approx0.724543$. [Код 3.2](3.2/main.py)

## 3.3. Метод наименьших квадратов

- **Что ищем.** Прямую и параболу, у которых сумма квадратов вертикальных отклонений от исходных точек минимальна.
- **Что делает код.** `fit_polynomial()` собирает систему для коэффициентов. `solve_gauss()` исключает неизвестные по очереди и затем восстанавливает их снизу вверх.
- **Один шаг.** Для прямой $P(x)=a_0+a_1x$ первое уравнение имеет вид $6a_0+(\sum_i x_i)a_1=\sum_i y_i$. Число 6 — количество точек. Именно эту строку код собирает при `k = 0` в `fit_polynomial()`. [Сборка системы](3.3/main.py#L33)
- **Что показать на графике.** Точки — таблица, линии — вычисленные многочлены. Возьми одну точку и сравни её высоту с высотой линии при том же $x$. Квадрат этой разности входит в сумму ошибок. У прямой сумма $8.6790$, у параболы $2.3557$. [Код 3.3](3.3/main.py)

## 3.4. Производные по таблице

- **Что ищем.** Первую производную в $x=2$, то есть наклон, и вторую, которая показывает, как этот наклон меняется. По трём соседним точкам строим мысленно параболу и считаем её производные по формулам.
- **Что делает код.** `differentiate()` берёт точки с $x=1.5,\ 2,\ 2.5$. Считает наклон слева и справа от $2$. На этой равномерной сетке их среднее даёт оценку первой производной в центре.
- **Один шаг.** `left_slope` равен $(0.69315-0.40547)/0.5=0.57536$. Справа наклон $0.44628$. В `difference` делим разность наклонов на расстояние между крайними узлами $2.5-1.5=1$ и получаем $-0.12908$. Код удваивает это число для второй производной. [Расчёт наклонов](3.4/main.py#L13)
- **Что показать.** Получилось $f'(2)\approx0.51082$ и $f''(2)\approx-0.25816$. По этим трём точкам видно, что функция растёт, а наклон уменьшается. [Код 3.4](3.4/main.py)

## 3.5. Численное интегрирование

- **Что ищем.** Интеграл функции $f(x)=x/(3x+4)^3$ от $-1$ до $1$. Разбиваем отрезок на части и складываем приближённые площади с их знаками.
- **Что делает код.** `midpoint_rule()` берёт высоту в середине интервала. `trapezoid_rule()` берёт среднее высот по краям. `simpson_rule()` берёт сразу два интервала и три высоты с весами $1,4,1$.
- **Один шаг.** При $h=0.5$ первый интервал идёт от $-1$ до $-0.5$. В `midpoint_rule()` его середина `midpoint` равна $-0.75$. Прибавляем к `result` вклад $0.5f(-0.75)\approx-0.06997$. [Первый прямоугольник](3.5/main.py#L8)
- **Что показать.** Каждый метод запускаем с шагами $0.5$ и $0.25$. Модуль разности двух ответов делим на $2^p-1$, где $p=2$ для прямоугольников и трапеций и $p=4$ для Симпсона. Это оценка ошибки мелкого шага по Рунге–Ромбергу. По сравнению с точным интегралом $-6/49$ ближе всех оказался Симпсон. [Код 3.5](3.5/main.py)
