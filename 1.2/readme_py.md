# Метод прогонки: как объяснить main.py

## Задание и исходные данные

Реализовать метод прогонки, задавая только три диагонали матрицы и вектор правых частей. С помощью программы решить систему:

```text
13*x1 - 5*x2 = -66
-4*x1 + 9*x2 - 5*x3 = -47
-x2 - 12*x3 - 6*x4 = -43
6*x3 + 20*x4 - 5*x5 = -74
4*x4 + 5*x5 = 14
```

Решить СЛАУ (систему линейных алгебраических уравнений) — найти числа `x1, ..., x5`, удовлетворяющие всем уравнениям одновременно. Матрица — таблица коэффициентов при неизвестных. Здесь она трёхдиагональная: в каждой строке участвуют только текущая неизвестная и её соседи.

В коде строка системы имеет вид:

```text
a[i] * x[i - 1] + b[i] * x[i] + c[i] * x[i + 1] = d[i]
```

| Обозначение | Смысл |
| --- | --- |
| `a[i]` | Коэффициент при предыдущей неизвестной; нижняя диагональ |
| `b[i]` | Коэффициент при текущей неизвестной; главная диагональ |
| `c[i]` | Коэффициент при следующей неизвестной; верхняя диагональ |
| `d[i]` | Число справа от знака равенства |
| `n = len(b)` | Число уравнений и неизвестных |
| `x[i]` | Найденное значение неизвестной |

Индексы начинаются с нуля: `x1` — это `x[0]`, последняя неизвестная — `x[n - 1]`. Второму уравнению соответствуют `a[1] = -4`, `b[1] = 9`, `c[1] = -5`, `d[1] = -47`.

У первой строки нет предыдущей неизвестной, у последней — следующей. Поэтому `a[0] = 0` и `c[n - 1] = 0` — служебные нули. Полная матрица не хранится.

## С чего читать программу

Начните с вызова `main()` внизу файла: условие `if __name__ == "__main__":` запускает её при выполнении файла.

В `main()` задаются списки `a`, `b`, `c`, `d` и размер `n`. Строка `P, Q, x = progonka(a, b, c, d)` передаёт данные в функцию решения. Переходите к `progonka()`: она проверяет одинаковую длину списков и условие `n >= 2`, затем выполняет два хода метода.

## Прямой ход: вычисляем P и Q

Идея — последовательно выразить каждую неизвестную через следующую:

```text
x[i] = P[i] * x[i + 1] + Q[i]
```

`P[i]` — множитель при следующей неизвестной, `Q[i]` — добавляемое число. Для этих промежуточных коэффициентов создаются списки `P = [0.0] * n` и `Q = [0.0] * n`.

**Первое уравнение.** Переносим слагаемое со следующей неизвестной вправо и делим на `b[0]`. Получаем формулы (1.5):

```python
P[0] = -c[0] / b[0]
Q[0] = d[0] / b[0]
```

Для нашего варианта это выражение `x1 = (5 / 13) * x2 - 66 / 13`.

**Остальные уравнения.** Заменяем предыдущую неизвестную её выражением через текущую. Коэффициент при текущей становится `b[i] + a[i] * P[i - 1]`. Деление на него даёт новые P и Q — формулы (1.4) и (1.6):

```python
for i in range(1, n):
    denominator = b[i] + a[i] * P[i - 1]
    # Здесь в программе проверяется возможность деления.
    P[i] = -c[i] / denominator
    Q[i] = (d[i] - a[i] * Q[i - 1]) / denominator
```

`denominator` — знаменатель. Цикл идёт от индекса `1` до `n - 1`: первая строка уже обработана. Каждый шаг использует предыдущие P и Q. При `c[n - 1] = 0` автоматически получается `P[n - 1] = 0`.

Перед делением проверяется знаменатель: `abs()` берёт модуль, `scale` — наибольший модуль коэффициентов строки, `eps = 1e-12` — относительный порог. Если модуль знаменателя не больше `eps * scale`, возникает `ValueError`; `except` в `main()` выводит сообщение и завершает работу. Продолжить обычную прогонку нельзя, но это не означает отсутствия решения. Отдельные нулевые коэффициенты разрешены.

## Обратный ход: вычисляем x

Все P и Q уже известны. Последний P равен нулю, поэтому последняя неизвестная равна последнему Q. Затем применяем формулу (1.7):

```python
x = [0.0] * n
x[n - 1] = Q[n - 1]

for i in range(n - 2, -1, -1):
    x[i] = P[i] * x[i + 1] + Q[i]
```

`range(n - 2, -1, -1)` задаёт индексы `n - 2, ..., 0`: идём от предпоследней неизвестной к первой с шагом `-1`. Для каждого `x[i]` значение `x[i + 1]` уже найдено.

`return P, Q, x` возвращает три списка в `main()`, где они выводятся на экран.

## Проверка решения и результат

В конце `main()` подставляем x в исходные уравнения. `left_part` — левая часть: начинаем с `b[i] * x[i]`, добавляем слагаемое с предыдущим соседом при `i > 0` и со следующим при `i < n - 1`.

```python
residual = left_part - d[i]
```

`residual` — невязка: разница между вычисленной левой частью и заданной правой. `max_residual` хранит наибольший её модуль среди всех строк. Значение около нуля показывает, что равенства выполняются с малой погрешностью.

При запуске получено:

```text
x = [-7, -5, 6, -4, 6]
Максимальная абсолютная невязка: 1.421085e-14
```

Невязка примерно равна `0.000000000000014` — это малая погрешность вычислений с дробными числами. Форматы `.6f` и `.6e` задают обычный и научный вид вывода. Внутри вычислений округления нет.

Для другого варианта достаточно заменить четыре списка в `main()`: все основные циклы зависят от `n`.
